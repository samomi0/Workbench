Tool template

This page runs inside a sandboxed iframe within the Workbench panel. It has access to the backend API via standard fetch calls.

Quick-start steps:

  • Duplicate the _template folder and remove the leading underscore from the folder name.
  • Edit tool.json — set a unique id, display name, and icon symbol id.
  • Replace this index.html with your tool UI.
  • Optionally add a Python module under backend/api/ and register it in app.py.
  • For mock services, add a file to backend/mock/services/ — it is auto-discovered on startup.

API access example:

fetch('/api/tags') returns the tag list. All workbench REST endpoints are available at /api/*.
